# FGO 模板截图说明

在这个目录放入游戏画面截图（PNG格式）供两个版本的脚本使用。

## 两个版本说明

- **轻量版** (`farmer_lite.py`) — 基于模板匹配，需要配置固定的技能序列
- **智能版** (`farmer_smart.py`) — 动态决策，自动识别战场信息，无需配置技能序列

## 必须的模板截图（两个版本都需要）

### 1. `attack_btn.png`
- **位置**：战斗画面，右下角的"Attack"按钮
- **作用**：识别战斗进行中状态
- **大小建议**：约 100x100 像素
- **截图方法**：在任意战斗中点击攻击前截图

### 2. `result_screen.png`
- **位置**：战斗结束后的结算画面（显示获得奖励、经验值等）
- **作用**：识别战斗是否结束
- **大小建议**：约 150x100 像素

### 3. `skill_target_select.png` ⭐ 新增（轻量版需要）
- **位置**：技能目标选择框出现时的画面（通常是屏幕中央出现目标选择框）
- **作用**：检测是否需要选择技能目标
- **大小建议**：约 150x150 像素
- **说明**：有些技能需要选择目标（如伤害技能），有些不需要（如增益技能）。截图时应该包含"目标选择框"的特征元素

## 推荐的模板截图（可选，让流程更稳定）

### 4. `bond_screen.png`
- **位置**：羁绊/好感度结算画面
- **大小建议**：约 150x100 像素

### 5. `ap_recover.png`
- **位置**：AP不足时的提示对话框
- **大小建议**：约 200x100 像素

### 6. `support_select.png`
- **位置**：选择助战画面的标志性元素
- **大小建议**：约 150x100 像素

### 7. `quest_confirm.png`
- **位置**：出发前的确认按钮
- **大小建议**：约 100x60 像素

### 8. `party_select.png`
- **位置**：队伍选择画面的标志性元素
- **大小建议**：约 150x100 像素

### 9. `start_quest_btn.png`
- **位置**：队伍选择后的"开始"或"出击"按钮
- **大小建议**：约 100x60 像素

## 智能版专用：区域坐标标定

智能版需要定位血条、NP槽、技能图标的位置以进行颜色分析。以下是默认坐标（1280x720 分辨率），**如果你的屏幕显示位置不同，需要调整**。

### 调整方法

1. **截一张完整的战斗画面** — 使用 ADB：
   ```bash
   adb -s 127.0.0.1:5555 exec-out screencap -p > battle_screen.png
   ```

2. **用截图工具（如 GIMP/Preview）测量像素坐标**：
   - 血条通常在屏幕上方，每个敌人一条（绿/黄/红色）
   - NP槽在屏幕下方攻击卡上方，三个仆人各一条（金黄色）
   - 技能图标在屏幕下方，每个仆人 3 个技能（小方块）

3. **修改脚本中的坐标常量**：
   - 轻量版：修改 `farmer_lite.py` 中的坐标常量无需改（已预设）
   - 智能版：修改 `farmer_smart.py` 中的 `ENEMY_HP_REGIONS` 和 `common/vision.py` 中的 `read_np_gauge` / `get_skill_regions` 的默认坐标

### 默认坐标参考（1280x720）
```python
# 敌方血条位置（估算）
ENEMY_HP_REGIONS = [
    (100, 40, 250, 60),      # 左敌
    (500, 40, 650, 60),      # 中敌
    (900, 40, 1050, 60),     # 右敌
]

# NP 按钮位置（下方，用于定位 NP 槽）
NP_BTNS = [(200, 520), (640, 520), (1080, 520)]

# 技能按钮位置
S1_SKILLS = [(90, 620), (160, 620), (230, 620)]
S2_SKILLS = [(430, 620), (500, 620), (570, 620)]
S3_SKILLS = [(760, 620), (830, 620), (900, 620)]
```

## 截图步骤

### 使用 ADB 命令行截图：
```bash
adb -s 127.0.0.1:5555 exec-out screencap -p > screen.png
```

### 截图后处理：
1. 用图片编辑软件打开 `screen.png`（预览、GIMP、Photoshop等）
2. 裁剪出需要的部分（保留足够的特征信息）
3. 保存为对应名称到本目录

## 提示

- **分辨率**：脚本默认 1280x720，其他分辨率需要按比例调整坐标
- **图片大小**：越小越快，但要保留特征
- **清晰度**：截图清晰，避免压缩失真
- **测试**：截完图后先运行脚本测试是否能识别
